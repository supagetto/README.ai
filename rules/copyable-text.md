# Copyable Text

**Format anything the user must copy so `/copy` lists it.**

The `/copy` picker lists fenced code blocks and blockquotes. It does not list inline code.

- Put commands and code the user must copy in a fenced code block. Tag it with the language.
- Put prose the user must copy in a blockquote.
- Put only the text to copy inside. Do not add a `$` prompt or comments that are not part of the text.
- Use inline code only to name things such as files, functions, or flags. Do not use it for text the user must copy.
