# Verify Before Claiming

**State only what you have checked. Label the rest.**

- Read the code, docs, or command output before stating how something behaves.
- Treat secondhand claims as unverified until checked: subagent reports, memory, session-start snapshots such as git status, earlier assumptions.
- Label any claim you have not checked as unverified.

This rule is working if the user stops catching invented facts.
